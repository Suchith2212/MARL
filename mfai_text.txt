ABSTRACT
Cooperating agents such as robots or drones often need to share information while operating over
communication links with limited capacity. This project studies how a cooperative multi-agent
reinforcement learning (MARL) team can use a limited average communication budget. Each agent
learns whether to transmit and, when it transmits, the precision at which to encode its message.
We formulate communication as an expected payload-bit constraint and propose a MAPPO-based
primal–dual training method with a learned transmission gate and quantiser. Since bandwidth-
limited communication, message pruning, and quantisation have all been studied previously, our
project focuses on a controlled empirical comparison: at matched communication costs, does learning
message precision improve over learned gating with fixed precision? We will evaluate this question on
small partially observable cooperative benchmarks and measure team return, actual communication
cost, and episode-level budget violations. Robustness to packet drops and delay is a secondary
experiment.
KeywordsMulti-agent reinforcement learning · Learned communication · Constrained optimisation · Bandwidth-

1 Introduction
Many real-world systems contain several decision makers that must coordinate even though each observes only part
of the situation. Examples include fleets of delivery drones, warehouse robots, and sensor networks. Multi-agent
reinforcement learning (MARL) provides methods for training such teams from experience. A common approach
is centralised training with decentralised execution (CTDE), as used in methods such as QMIX [1] and MAPPO [2].
Under partial observability, communication can help agents combine information and coordinate their actions. Prior
work has explored learned communication protocols and message aggregation [3, 4, 5].
Communication is not free in real systems: links have limited capacity, transmissions consume energy, and packets
may be delayed or lost. Prior MARL work has addressed communication constraints through message pruning [ 6],
communication scheduling [7], constrained event-triggered communication [ 8], and temporal message control [ 9].
Dynamic Size Message Scheduling (DSMS) adapts message size under a bandwidth budget by retaining a variable
number of clipped Fourier components [ 10]. CACOM also uses learned step-size quantisation in a context-aware
communication protocol [11]. Our proposed comparison differs from DSMS in the representation decision: we vary the
bit precision of each message entry, whereas DSMS varies the number of retained frequency components. Bandwidth
limitation, gating, and compression are established research topics; our project will not claim them as new in themselves.

value beyond learning when to transmit. Given a target payload budget, we will compare a learned gate with fixed
precision against a learned gate combined with a learned quantiser. The primary outcome is the return–cost trade-off

Project objectives.We will (i) implement a reproducible MAPPO communication baseline with a configurable

4.3 Environments and metrics
We will use a partially observable setup: MPE observations will be restricted by an observation radius, and/or Level-
Based Foraging will use a limited sight range [ 14, 15]. In Phase 1, we will run two screening checks. First, full
communication must outperform no communication by at least 0.10 on a task score normalised to [0,1] using fixed,
documented endpoints, and the paired-seed 95% confidence interval for the difference must exclude zero. Second, we
will run full communication at each fixed width in {1,2,4,8} . If these precision-screening returns are effectively flat
(all pairwise differences below 0.10 normalised score), learned precision will be deprioritised and the finding reported;
it will not be presented as a promising improvement. We will report team return, discounted-normalised cost, plain

4.4 Research questions and planned results
RQ1 Does learned precision help at matched cost?Compare learned gating plus learned quantisation with the
best return–cost frontier across fixed widths {1,2,4,8} . Planned output: return–cost curves, confidence
intervals, and selected bit-width summaries. A null result, where learned precision does not improve over
the best fixed-width baseline, will be reported as a valid finding.
RQ2 Can the target expected budget be reached reliably?Measure discounted-normalised expected cost and
episode-level violation rate across several target budgets. Planned output: cost and violation plots for the
primal–dual policy and matched-cost baselines.
RQ3 How sensitive are results to channel faults?As a secondary experiment, evaluate packet drops and
delays, including test conditions that differ from training. Planned output: returns, measured costs, and
nonnegative degradation under each stated channel condition.
Stretch goals (time permitting):a budget-conditioned single policy and one SMACv2 map. These will not be required
for the primary project conclusion.
